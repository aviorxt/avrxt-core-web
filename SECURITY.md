# Security policy

Please report suspected vulnerabilities privately to the repository owner rather than opening a public issue. Include the affected route or component, reproducible steps, impact, and a minimal proof of concept when safe.

Do not test with destructive traffic, access data that is not yours, target third-party services, or disclose an issue before a fix is available. Maintainers should replace this file with a monitored disclosure address before production use.

Only the latest release is expected to receive security fixes.
