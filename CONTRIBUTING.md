# Contributing

Thanks for helping improve Core Web.

1. Open an issue for significant behavioral or architectural changes.
2. Create a focused branch and keep commits reviewable.
3. Do not include credentials, personal data, copyrighted media, or copied brand assets.
4. Run `npm run lint` and `npm run build` before opening a pull request.
5. Describe user-visible changes, security implications, and manual verification steps.

By contributing, you agree that your contribution is licensed under the MIT License.
